# References

Ground truth from real designs, stored as text and numbers so it survives a
public repo. No third-party images or video are committed here. When a
reference is needed visually, open the live site in the browser pane.

Each file follows `TEMPLATE.md`. Add one whenever a session digests a new
reference (`methods/digest-a-reference.md`).

## Sites worth studying live (not stored)

- creed.md: clean monochrome UI over saturated full-bleed photos. Geist. Lucide.
  Sixteen sections, most animated. The rich-ground route.
- naano.xyz: clean off-white with no photo, dense realistic product mocks with
  real numbers in every section. Inter. The dense-data route.
- origami.chat: serif display, one committed metaphor made physical, near
  monochrome.
- emilkowal.ski: warm off-white, small refined sans, italic serif accents. The
  quiet personal end.
- Linear, Vercel, Raycast: product UI density done with three greys.
- DaVinci Resolve, Frame.io: dark film chrome with one accent.

When one of these is used as a reference, digest it into a file here.
