# Elide brand system — the reference for any Elide work

Source: `~/workspace/design-system` (local static site, v1.3, April 2026).
Open `index.html` there and read `color.html`, `typography.html`,
`components.html`, `motion.html` before building anything for Elide.

## How to use it

This is a brand specification, not a method. sri-design supplies the method;
the Elide system supplies the values. When the two disagree on a value, the
Elide system wins for Elide work.

Extract from it the same way as any reference: read the token pages, copy the
hexes and faces, note the tone pillars in `brand.html`, and fill the brief
from those. Do not restyle the brand to taste.
