# Anti-slop checklist

Run before showing any design. Every "no" is a fix, not a note.

## Idea
- [ ] I can point at the thing on the page that IS the idea.
- [ ] Each viewport has one subject and the whitespace frames it.

## Reference
- [ ] The build resembles the named reference in a side-by-side, not a generic clean page.
- [ ] Font, weights, tracking, greys, and motion were read from a source, not typed from memory.

## Color
- [ ] No accent chosen by habit. No purple or indigo. No default orange.
- [ ] Greys plus at most one accent plus status colors. Counted.
- [ ] Accent appears only where it means something.
- [ ] No corner glow with flat corners. No gradient chrome.

## Ground and depth
- [ ] A real ground or dense real data. Not a white void.
- [ ] Section count matches the depth budget. At least three move.
- [ ] Every demo shows specific believable content. No lorem, no "Feature 1".

## Type
- [ ] Three UI sizes within 2px plus one big jump.
- [ ] Negative tracking on display. No pure black.
- [ ] Tabular numerals on everything numeric.
- [ ] Weights 400 and 500 only.

## Icons and marks
- [ ] Every icon pulled from a real source. One set, one grammar.
- [ ] Legible at its rendered size. Looked at, not assumed.
- [ ] No hand-drawn logo.

## Motion
- [ ] Two curves, the duration ladder, press scale on buttons.
- [ ] Reduced motion guarded and tested.
- [ ] Nothing animates only to get attention.

## Copy
- [ ] No banned words. Sentences short. One "X. Not Y." moment.
- [ ] CTAs are verb plus object.

## Libraries
- [ ] Toasts, menus, OTP, DnD, lists, counters use the trusted library.

## Verification
- [ ] Rendered and screenshotted at desktop and mobile widths.
- [ ] Text over texture passed a contrast check.
- [ ] Left edges counted against the grid contract.
- [ ] Three decisions on the page that a template would not have made. Named.
